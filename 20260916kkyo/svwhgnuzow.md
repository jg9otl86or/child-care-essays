# 【科普】儿童反复便血，警惕肠息肉！

> 更新时间：2026-09-16 (UTC+8)

小明（化名）是一名3岁男孩，近半年因“反复便血”辗转就诊于各家医院，考虑“肛裂”、“过敏”等情况，治疗后便血情况仍然没有改善。反复便血，到底是怎么回事呢？近日，小明妈妈带着他来到我院小儿消化门诊，小明在专家的建议下进行了结肠镜检查，内镜下发现了导致小明便血的“罪魁祸首”——一枚直径约1.8cm的肠息肉！儿童也会长肠息肉吗？是的，下面我们就聊一聊儿童肠息肉和其他引起儿童便血的原因。

Q

**什么是儿童肠息肉？**

儿童肠息肉是一类凸起到消化道腔内的黏膜隆起，局限性增生后形成的组织，是引起儿童下消化道出血最常见的病因之一。其中幼年性息肉是儿童肠息肉最常见的类型。

Q

**儿童幼年性息肉有哪些特点****？**

幼年性息肉多发于直肠、乙状结肠，通常为单发，占儿童肠息肉的90%，是良性错构瘤，临床最主要的表现为无痛性便血，如果息肉位置较高，也易导致小儿腹痛症状。长期慢性失血，可导致小儿贫血，约有1/3患儿出现轻度贫血，是小儿下消化道出血的最常见原因，约占儿童下消化道出血的90%。

Q

**发现孩子有肠息肉该怎么办？**

在成长中息肉有自行脱落的可能，但是如果发现还是建议尽早切除，以免后患。随着儿童内镜技术在临床推广应用，肠息肉患儿的诊断与治疗变得更加便捷。结肠镜检查是发现儿童肠息肉最佳的检查方法，检查的同时即可在内镜下行息肉切除，痛苦小且安全，是目前儿童肠息肉检查、治疗的最主要方法。

Q

**除了肠息肉，还有哪些情况会引起儿童便血****？**

▎肛裂：是1岁以下婴儿直肠出血的最常见原因，在年龄较大儿童及成人中也较常见。展开会阴部皮肤外翻肛管即可诊断。

▎肠套叠：多见于4-10个月婴儿。临床表现为阵发性腹痛或哭闹，部分伴有呕吐和精神萎靡，数小时后有果酱样血便。体检在右侧腹或横结肠处可及一腊肠样肿块。B超检查在肠套叠部位可见同心圆或靶环状肿块图像。

****

▎过敏性结肠炎：常见于对牛奶或大豆蛋白的炎症反应。患儿可出现腹泻、大便隐血或肉眼可见的便血，如配方喂养，建议氨基酸奶粉或深度水解奶粉喂养，如母乳喂养，应询问母体饮食并去除可能造成过敏的食物。

****

▎过敏性紫癜：通常发生于病毒感染后，体格检查可见皮肤紫癜性皮疹。累及胃肠道者可出现便血并伴有明显腹痛，表现为大便潜血阳性、大量鲜红色血便或黑便。腹部超声检查见肠管壁增厚、水肿有提示性作用，有条件的可尽早行胃镜检查协助诊断。

****
▎美克尔憩室：在婴幼儿和儿童期较多见，因卵黄囊退化不全所致，其特点是便血量大，暗红色，无痛性，可反复发作，可出现贫血症状。如出血量较大，甚至可有休克表现。因憩室内有异位胃黏膜或胰腺组织造成腐蚀产生溃疡出血，甚至穿孔。超声检查有助于诊断，手术结果为诊断梅克尔憩室“金标准”。

****

▎炎症性肠病：包括溃疡性结肠炎和克罗恩病，便血同时伴有发热、腹痛、腹泻，存在慢性或严重症状并伴有体重减轻或生长障碍的患儿常可疑该病。行结肠镜检查可明确诊断。

引起儿童便血的原因有很多，各位家长朋友，如果孩子出现反复便血，排便习惯改变，贫血，体重减轻等情况，一定要及时带孩子去正规医院检查，并配合医生进行规范治疗。
