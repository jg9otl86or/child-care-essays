# 夫妻多年不明原因不孕怎么办快来试试这几种方法!，考虑不明原因不孕症

生活中，有很多人遇到相同的情况，那不明原因不孕到底能不能怀孕呢?这期我们就告诉大家几种有效的治疗方法。

**01评估生育力**

可以通过医生询问病史、体格检查以及精液分析来评估男性生育能力。推荐进行≧2 次精液检查。

02女性不孕的评估

子宫输卵管通畅度检查：推荐首选 X 线下子宫输卵管造影(HSG )

评估排卵检查：①B超监测卵泡发育 ②黄体中期孕酮测定(≥3ng/ml )③尿LH监测 ④月经规则的女性，有排卵的可能性大;不推荐用基础体温、子宫内膜活检评估排卵。

推荐年龄≥35 岁的女性，可尽早进行卵巢储备功能的评估：包括基础性激素、AMH、超声监测基础卵巢窦卵泡数等。

有条件推荐行诊断性腹腔镜检查：如对阑尾炎，慢性盆腔炎, 异位妊娠史等或子宫内膜异位症的症状、体征等不明原因不孕患者可推荐进行诊断性腹腔镜评估检查;对于不孕年限长于(大于3年)，影像学检查未提示明显异常，可以考虑行腹腔镜评估检查。

**02不明原因不孕症的治疗**

无法找到夫妇不孕不育的原因并不意味着没有原因，部分不明原因不孕夫妇可能仅是生育延迟，仍有自然怀孕的可能，因此，不明原因不孕症的治疗应根据夫妇年龄、不孕年限、生育需求的迫切性等因素由医生给制定个性化的、恰当的治疗建议。

**期待治疗**

不明原因不孕夫妇未经过任何治疗，有一部分夫妇可成功妊娠。这可能是不明原因不孕夫妇处于正常生育力波动的下限，并没有呈现出生殖功能缺失。女性的生殖能力在 32岁时开始逐渐下降，37岁后下降更快，因此不孕妇女年龄是影响夫妇期待治疗成功率的最重要指标。

推荐年龄35 岁的不明原因不孕女性(不孕评估检查无卵巢功能减退证据)，不孕年限≤2 年，可先选择期待治疗6 月~12月;仍未孕，可考虑IUI或IVF-ET。不推荐年龄35岁、不孕年限3年的不明原因不孕夫妇进行期待治疗。

**人工授精(IUI)**

IUI 是将优化处理过的精子悬液通过导管直接注入子宫腔内使精卵自然结合达到妊娠。不明原因不孕夫妇行IUI助孕，一方面是通过诱导排卵治疗了隐蔽的排卵缺陷，从而增加了可用于受精的卵子而提高妊娠的可能性;另一方面可能是采用 IUI 的方式将洗过的精子进入子宫腔增加了活动精子的密度，最大限度地提高了受精的机会。

推荐年龄35 岁且不孕年限2年，或年龄 35-39 岁可行IUI助孕3-6个周期。对于40 岁患者，可考虑尝试IUI 治疗3个周期。如果仍不孕，可考虑IVF-ET助孕。

体外受精-胚胎移植(IVF-ET)

IVF-ET被认为是多数不孕症患者的最终治疗手段，因此，IVF 治疗也是不明原因不孕患者的治疗方法之一。

①可推荐35 岁不明原因不孕患者经过期待治疗 6~12 月以及IUI 3-6个周期治疗仍未受孕的可考虑进行IVF-ET助孕。

②对于35-39 岁不孕年限较长(3年)的患者也可以考虑直接行 IVF-ET助孕。

③对于40岁患者者，如不孕年限短可先尝试IUI治疗周期，如果仍未孕即考虑转IVF;而年龄大于 42 岁的女性则可以不经过其他治疗方式，直接选择IVF助孕。
